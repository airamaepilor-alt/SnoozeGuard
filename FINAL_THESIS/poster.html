Abstract

Driver drowsiness is a leading cause of road traffic fatalities. SnoozeGuard is a multi-platform, AI-driven real-time drowsiness monitoring system that uses Google's MediaPipe Face Landmarker — processing 478 facial landmarks and 52 blend shape coefficients — to detect drowsiness from a smartphone's front camera without vehicle modification.


The system fuses four signals: yawning, head nodding, sustained head tilt, and sudden braking into a configurable 10-level drowsiness score. Alert escalation ranges from voice/vibration to a paired ESP32 IoT alert device. At levels 9–10, an automatic emergency notification (push + PhilSMS) is sent to the driver's designated guardian after a 120-second countdown.


The system operates offline-first via SQLite with Supabase cloud sync and was evaluated using the ISO/IEC 25010 software quality model with active driver respondents (ages 22–35) using a physical driving simulator prototype.

3

4
Implement emergency notification pipeline via Expo Push + PhilSMS SMS to active guardian at levels 9–10 after 120-second countdown
5

6
Evaluate SnoozeGuard against ISO/IEC 25010 across 8 quality characteristics using structured Likert-scale survey

Conclusion
  • MediaPipe Face Landmarker enables reliable real-time multi-signal drowsiness detection on consumer Android hardware without specialized vehicle hardware.
  • A configurable 10-level scoring model provides proportional escalation avoiding binary false-alarm fatigue.
  • ESP32 IoT peripheral with MQTT + BLE dual-path extends alerts beyond the smartphone screen with level-calibrated physical responses.
  • Closed-loop emergency notification (Push + PhilSMS) provides guardian response capability absent from existing smartphone DMS apps.
Discussion

SnoozeGuard addresses the accessibility gap in driver monitoring by leveraging the ubiquitous smartphone camera and on-device ML inference — eliminating the need for costly vehicle-integrated DMS systems. The multi-signal fusion approach (yawn + head + tilt + brake) outperforms single-signal eye-closure systems identified in the literature, particularly under occlusion from eyewear and varying lighting. The IoT peripheral extends alert reach to physical space, reducing reliance on the driver's attention to their phone screen. The closed-loop emergency notification pipeline, combining Expo Push and PhilSMS, provides the guardian response mechanism absent from all existing smartphone DMS applications. Offline-first SQLite architecture ensures continuous session recording critical for Philippine road environments with intermittent connectivity.
